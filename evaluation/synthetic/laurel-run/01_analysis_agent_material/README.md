# Laurel Run Trailer Works — analysis-agent materials

**Entirely fictional academic test case, snapshot October 31, 2026.** The fictional company, names, dealers, suppliers, prices, records, activities and company financial figures are invented. Named software and external research sources are real. The case is not a description of a real manufacturer. The reporting year is November 2025–October 2026.

The company sells through 80 independent dealers. It has 50 employees and 1,500 completed and shipped trailers in the reporting year. The data dictionary explains completeness, illustrative samples, keys, units, dating, and planned versus completed events. Read it before interpreting the CSVs. Social-channel accounts and results are fictional and do not establish attributable orders or sales.

This folder contains no evaluator answer key. Give an analysis agent access to **this folder only**, not the parent folder or its evaluator-only sibling. The case is intentionally built for analysis; its company-facing documents describe work and records, not an evaluation or prescriptions. The separate evaluator material is not included here. Files are plain Markdown and CSV; download the folders together to preserve relative paths.
