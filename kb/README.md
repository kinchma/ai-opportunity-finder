# Curated knowledge base

One folder per industry plus `general/`. Each `.md` file starts with a small header, then `---`,
then the text. Paragraphs are split on blank lines.

```
source: Name of the document or publisher (shown to the owner as the citation)
url: https://link-or-blank
industries: comma, separated, tags (use * for general guidance that applies to every industry)
---
Paragraph one...

Paragraph two...
```

IMPORTANT: the files in this starter set are author-written notes for the course project,
not published sources. Their `source:` line says so. Before the final report, replace or
supplement them with real, citable documents (industry association guides, vendor case
studies, government or consulting reports) and fill in the `source:` and `url:` lines.
To support a new industry, add a folder and set the `industries:` tags to words a business
in that industry would use to describe itself.
