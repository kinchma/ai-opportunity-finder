Frequently asked questions

Can I buy a trailer directly from the factory?

No. In this fictional example, Laurel Run sells through independent dealers rather than directly to retail customers. Dealers set their own retail prices.

How do I find the carrying capacity?

Read the certification and load labels on the completed trailer and account for installed equipment. An axle rating or nominal trailer dimension is not a payload rating.

Can I print these resources?

Yes. These are ordinary HTML pages; use your browser's print command to keep a copy. No download or account is required.
